# Aurio Studio support

Public support website for Aurio Studio 2.0 for iPhone and iPad, hosted with GitHub Pages.

- Support: https://casaxmore.github.io/Aurio-support/
- Privacy policy: https://casaxmore.github.io/Aurio-support/privacy.html
- Contact: casaxmore@gmail.com

`index.html` contains the English support page. `privacy.html` renders the current English policy, also included as `PRIVACY_POLICY.md`. `icono.png` is the current Aurio Studio icon. `app-ads.txt` retains the existing advertising declaration.
